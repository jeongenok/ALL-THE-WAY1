# 핏로그

아이폰 화면에 맞춘 개인 운동 일지입니다. 별도 라이브러리 없이 HTML, CSS, JavaScript로 동작합니다.

## 기능

- 체중, 키, 나이 프로필 저장 및 BMI 참고값 표시
- 운동 종목, 부위, 날짜 기록
- 세트마다 중량과 반복 횟수를 따로 입력하고 세트 행 추가
- 운동 기록을 날짜별로 묶어서 확인
- 오늘의 운동 기록 카드를 눌러 종목·세트·날짜·메모를 수정
- 내 몸 프로필에 성인 운동 기준 단백질·수분·탄수화물 참고량 표시

섭취량은 체중을 바탕으로 한 참고 범위입니다: 단백질 1.4–2.0 g/kg, 낮은 운동량 기준 탄수화물 3–5 g/kg, 수분 30–35 mL/kg. 수분과 탄수화물 필요량은 운동량, 성별, 날씨, 식사 구성과 건강 상태에 따라 달라집니다.
- 주간 운동일·세트·종목 요약과 날짜별 일지
- 기록을 현재 기기에 저장하고 앱 화면을 오프라인에서 열기

## 아이폰에서 사용하기

이 폴더를 HTTPS를 지원하는 정적 웹 호스팅에 올린 뒤, 아이폰 Safari에서 앱 주소를 열고 공유 메뉴에서 **홈 화면에 추가**를 선택하세요. 첫 접속 후 앱 화면 파일은 오프라인에서도 열 수 있습니다.

기록은 브라우저의 기기 내 저장소에 보관되며 계정 동기화나 백업은 제공하지 않습니다. 브라우저 데이터가 지워지면 운동 기록도 함께 삭제될 수 있습니다.
